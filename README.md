# Sprint 7 - Proyecto

Esta aplicación web fue desarrollada con Streamlit para analizar un conjunto de datos de anuncios de venta de vehículos.

Funcionalidades:

- Visualización de un histograma del kilometraje (odometer).
- Visualización de un gráfico de dispersión entre precio y kilometraje.
- Interfaz interactiva desarrollada con Streamlit.
